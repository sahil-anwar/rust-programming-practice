# Original Semester Exercises

These are the original Rust exercises from the Advanced Programming semester, reorganized by topic. Source code has not been rewritten. Folder names have been normalized to lowercase `snake_case`.

| Folder | Contents |
| --- | --- |
| `01_fundamentals` | Variables, constants, scope, and code blocks |
| `02_data_types` | Primitive and compound data types, strings |
| `03_control_flow` | Loop exercises |
| `04_rust_language_features` | Compiler directives, errors, operators |
| `05_ownership_and_borrowing` | Ownership, borrowing, mutability, dereferencing |
| `06_testing` | Unit testing |
| `07_assessments` | Exam practice |

Some files may be incomplete experiments or intentionally contain compiler errors, reflecting the original learning process.
